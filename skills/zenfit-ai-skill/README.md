## 🌟 Highlights & Core Features

- **3D Morphometric Body Predictor**: Infer 50+ detailed anatomical vectors (chest, waist drop, shoulder slope, inseam) from lightweight statistical anchors
- **Garment CAD Ease Tensor**: Compute mechanical ease allowance (Garment - Body) and simulate fabric elastane stretch dynamics
- **Cross-Brand Vanity Sizing Normalizer**: Map size variations across 15,000+ brands and calibrate subjective fit preferences (tailored vs. oversized)
- **Pre-Checkout Zero-Return Arbiter**: Intercept apparel purchases to evaluate fit confidence percentage, vetoing high-risk misfits to slash reverse logistics

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenfit workflow
npx genpark run zenfit --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenfit --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenfit_execute`: Primary autonomous execution tool with schema validation.
- `zenfit_audit`: Non-destructive state assessment and discrepancy scanner.
