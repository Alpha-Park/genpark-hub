# nexad-ai-skill

## Overview
Automate multi-variant creative copywriting and creative asset structure variations testing. Direct ad copy optimizations.

## Core Capabilities
- **Copywriter Pro**: Generate engaging, high-conversion copy for multi-channel digital campaigns
- **A/B Variant Generator**: Create multiple distinct copy variants for performance testing
- **Asset Structure Planner**: Design visual and text hierarchies optimized for ad networks

## Usage Guide
When starting a session using this skill:
1. Align ad copy tone with brand tone and target audience specifications
2. Verify length limitations for target channels
3. Compile generated variants into a structured output format for easy deployment
