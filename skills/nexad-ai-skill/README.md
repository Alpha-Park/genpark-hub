## 🌟 Highlights & Core Features

- **Copywriter Pro**: Generate engaging, high-conversion copy for multi-channel digital campaigns
- **A/B Variant Generator**: Create multiple distinct copy variants for performance testing
- **Asset Structure Planner**: Design visual and text hierarchies optimized for ad networks

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute nexad workflow
npx genpark run nexad --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run nexad --execute
```

## 🛠 MCP Tools & Agent Protocol
- `nexad_execute`: Primary autonomous execution tool with schema validation.
- `nexad_audit`: Non-destructive state assessment and discrepancy scanner.
