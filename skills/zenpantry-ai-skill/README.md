## 🌟 Highlights & Core Features

- **Digital Twin Pantry State Machine**: Ingest online grocery e-receipts and delivery manifests to model household stock depletion velocity
- **Nutritional Macro CSP Solver**: Formulate multi-objective linear constraints balancing daily protein/carb/fat targets and <25-minute weeknight prep times
- **Zero-Waste Perishable Amortizer**: Cluster fresh herbs and produce across multiple weekly meals to reduce domestic food waste by 60%
- **Federated Grocery Knapsack Fulfillment**: Map ingredient lines to store SKUs across Instacart, Whole Foods, and Kroger while optimizing free-delivery tiers

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenpantry workflow
npx genpark run zenpantry --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenpantry --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenpantry_execute`: Primary autonomous execution tool with schema validation.
- `zenpantry_audit`: Non-destructive state assessment and discrepancy scanner.
