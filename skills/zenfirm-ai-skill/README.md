## 🌟 Highlights & Core Features

- **Universal Protocol Broker**: Transpile between MCP, ACP, UCP, TAP, and PAP commerce standards
- **In-Chat Checkout Engine**: Render compact interactive checkout cards and execute 1-tap purchases in messenger
- **Merchant MoR Protector**: Ensure merchant retains Merchant of Record status, direct customer LTV, and CRM ownership
- **Passkey Biometric Gate**: Authorize transaction settlement via device-bound FIDO2 credentials in <400ms

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenfirm workflow
npx genpark run zenfirm --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenfirm --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenfirm_execute`: Primary autonomous execution tool with schema validation.
- `zenfirm_audit`: Non-destructive state assessment and discrepancy scanner.
