# trooly-ai-skill

## Overview
Qualitative customer research and customer empathy engine. Automates scraping of qualitative feedback and builds in-depth persona blueprints.

## Core Capabilities
- **Empathy Engine**: Build qualitative persona blueprints
- **User Feedback**: Auto-scrape reviews across targeted platforms
- **Format Output**: Compile empathy graphs and core triggers

## Usage Guide
When starting a session using this skill:
1. Confirm target customer niche before execution
2. Verify qualitative data density limits
3. Render output using structured markdown templates
