## 🌟 Highlights & Core Features

- **Virtual Cursor Co-Pilot**: Navigate non-commodity storefronts with visible autonomous cursor and macro flaw zoom
- **Collector Memory Engine**: Maintain cross-session registry of owned portfolio, grading tolerances, and past rejected offers
- **Bilateral Negotiation Arbiter**: Formulate comp-backed opening bids and evaluate seller counter-offers in real-time
- **Omnichannel Watchdog**: Track seller reserve drops and alert collector via WhatsApp/Telegram for instant in-chat counter-offers

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenpal workflow
npx genpark run zenpal --demo

npx genpark run zenpal --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenpal_execute`: Primary autonomous execution tool with schema validation.
- `zenpal_audit`: Non-destructive state assessment and discrepancy scanner.
