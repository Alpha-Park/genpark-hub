## 🌟 Highlights & Core Features

- **5C ACO Auditor**: Benchmark enterprise SKUs against Completeness, Context, Citations, Correctness, and Acquisition
- **Digital Twin Shopper Swarm**: Simulate thousands of multi-archetype AI buyer personas across ChatGPT, Gemini, Rufus, and Sparky
- **Hallucination Detection Radar**: Continuously scan LLM outputs to catch factual model errors and deploy corrective Schema.org JSON-LD manifests
- **Share of Model Forecaster**: Track brand recommendation win/loss ratios against competitors and diagnose prompt elimination bottlenecks

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenzoma workflow
npx genpark run zenzoma --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenzoma --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenzoma_execute`: Primary autonomous execution tool with schema validation.
- `zenzoma_audit`: Non-destructive state assessment and discrepancy scanner.
