## 🌟 Highlights & Core Features

- **Multimodal Fault Diagnostic**: Ingest model plate OCR, error codes, and acoustic recordings to isolate appliance failure root causes
- **Exploded OEM CAD Resolver**: Cross-reference 5M+ industrial parts schematics to pinpoint exact OEM part numbers and certified alternatives
- **50% Economic Lifecycle Arbiter**: Calculate depreciated asset value vs. repair cost to issue definitive Repair vs. Replace decisions
- **RSMeans Labor Rate Auditor**: Deconstruct contractor lump-sum bids and benchmark against regional trade prevailing wage tables to stop price gouging
- **Direct-to-Part Wholesale**: Enable direct consumer procurement of verified OEM/aftermarket components bypassing 200% trade markup

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenfix workflow
npx genpark run zenfix --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenfix --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenfix_execute`: Primary autonomous execution tool with schema validation.
- `zenfix_audit`: Non-destructive state assessment and discrepancy scanner.
