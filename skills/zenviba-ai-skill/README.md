## 🌟 Highlights & Core Features

- **Scene Context Encoder**: Translate real-life occasions, weather, and dress codes into vibe vectors
- **Dual-Persona Stylist**: Angel (affirmative validation) & Devil (brutal honesty roast) fashion critique
- **Virtual Styling Room**: Assemble multi-layered outfits adhering to visual harmony rules
- **Look-to-SKU Mapper**: Resolve aesthetic moodboards to shoppable merchant SKUs via zenlumen & zenprocure
- **Vibe Journal Tracker**: Maintain private local aesthetic taste evolution vector in OpenClaw storage

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenviba workflow
npx genpark run zenviba --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenviba --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenviba_execute`: Primary autonomous execution tool with schema validation.
- `zenviba_audit`: Non-destructive state assessment and discrepancy scanner.
