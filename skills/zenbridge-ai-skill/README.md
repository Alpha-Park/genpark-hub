## 🌟 Highlights & Core Features

- **PAP Discovery**: Auto-resolve /.well-known/poppy.json merchant endpoints
- **OAuth Broker**: Scoped guest and authenticated session tokens
- **Dynamic Router**: Dual-path routing (PAP API vs. Resident Browser fallback)
- **A2B Negotiator**: Counteract merchant Seller AI dynamic pricing and retention traps

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenbridge workflow
npx genpark run zenbridge --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenbridge --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenbridge_execute`: Primary autonomous execution tool with schema validation.
- `zenbridge_audit`: Non-destructive state assessment and discrepancy scanner.
