## 🌟 Highlights & Core Features

- **Multimodal Aesthetic Seeker**: Translate natural language prompts and reference photos into structured style vectors
- **Say More Refinement Engine**: Dynamically steer recommendations via conversational feedback in <50ms
- **Aesthetic Vector Graph**: Deconstruct SKUs into 50+ dimensional sensory and silhouette attributes
- **In-Store Search SDK**: Replace static merchant search bars with brand-native conversational AI stylists
