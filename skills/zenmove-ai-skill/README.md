## 🌟 Highlights & Core Features

- **USDOT & MC Authority Sentry**: Real-time FMCSA SAFER database queries to identify unlicensed rogue brokers, revoked authorities, and chameleon carrier scams.
- **Federal 110% Delivery Cap Enforcement (49 CFR § 375.407)**: Enforces statutory mandates compelling movers to release household goods upon tender of 100% of binding or 110% of non-binding estimates.
- **Computer Vision Volumetric Weight Proof**: Analyzes pre-move room photos and videos to calculate certified cubic-foot volume, dismantling fake scale overage slips.
- **Emergency Federal Hostage Load Package (49 U.S.C. § 14915)**: Dispatches emergency complaint dossiers to the USDOT OIG, state Attorneys General, and local police civil standby units to compel immediate unloading of hijacked goods.

## 🚀 Quick Start & CLI Usage

```bash
# Verify interstate mover licensing and safety record
npx genpark run zenmove --usdot "3892011" --verify-authority

# Audit delivery day surcharge extortion against federal 110% rule
npx genpark run zenmove --estimate 2800 --demanded 5900 --type "BINDING" --dispatch-emergency
```

## 🛠 MCP Tools Exposed

- `zenmove_verify_carrier`: Queries FMCSA SAFER database for licensing and insurance status.
- `zenmove_audit_estimate`: Evaluates binding vs. non-binding quotes against 110% statutory delivery caps.
- `zenmove_estimate_volume`: Computes certified cubic-foot volumetric baselines from room photos.
- `zenmove_dispatch_hostage_dispute`: Generates emergency law enforcement and DOT regulatory complaints.
