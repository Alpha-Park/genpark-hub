## 🌟 Highlights & Core Features

- **Universal Catalog Indexer**: Normalize heterogeneous web schemas into 100M+ unified canonical product graph
- **Multimodal Entity De-Duplicator**: Cluster identical physical SKUs across retailers using vision embeddings and title semantics
- **Open MCP Search Engine**: Expose search_products, lookup_product_url, and compare_merchant_offers tool endpoints
- **Universal Affiliate Clearing Hub**: Auto-inject compliant affiliate tracking tokens and attribute commission splits via x-user-id

---

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenchannel workflow
npx genpark run zenchannel --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenchannel --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenchannel_execute`: Primary autonomous execution tool with schema validation.
- `zenchannel_audit`: Non-destructive state assessment and discrepancy scanner.
