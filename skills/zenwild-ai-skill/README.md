## 🌟 Highlights & Core Features

- **Share of Model Radar**: Audit brand recommendation rank and sentiment across ChatGPT, Claude, Rufus, and Perplexity
- **Citation Graph Miner**: Reverse-engineer Reddit, review sites, and YouTube discussions driving competitor agent recommendations
- **Agents.json Synthesizer**: Deploy and maintain standard /.well-known/agents.json machine-readable manifests
- **PDP Attribute Enricher**: Auto-inject 40+ structured Schema.org attributes to prevent agent retrieval disqualification

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenwild workflow
npx genpark run zenwild --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenwild --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenwild_execute`: Primary autonomous execution tool with schema validation.
- `zenwild_audit`: Non-destructive state assessment and discrepancy scanner.
