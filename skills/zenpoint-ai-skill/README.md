## 🌟 Highlights & Core Features

- **Merchant MCC Radar**: Pre-screen merchant category codes to route checkout to the card yielding maximum category multipliers
- **Card-Linked Offer Auto-Stacker**: Automatically detect and clip targeted Amex, Chase, and Citi merchant cashback promos in <100ms
- **Cents-Per-Point Arbitrageur**: Dynamically compute CPP conversion hurdles to decide between cash checkout vs. airline/hotel award redemptions
- **Transfer Partner Route Compiler**: Map points across 30+ airline frequent flyer and hotel programs, harvesting active transfer bonus multipliers

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenpoint workflow
npx genpark run zenpoint --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenpoint --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenpoint_execute`: Primary autonomous execution tool with schema validation.
- `zenpoint_audit`: Non-destructive state assessment and discrepancy scanner.
