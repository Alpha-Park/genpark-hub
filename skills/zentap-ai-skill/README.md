## 🌟 Highlights & Core Features

- **RFC 9421 HTTP Message Signer**: Generate asymmetric Ed25519 and ECDSA cryptographic signatures across HTTP methods, target URIs, authorities, and content digests
- **Agent Registry Resolver**: Broadcast and resolve public keys via open agent registries, enabling merchant edge firewalls to authenticate agents in <5ms
- **Consumer Mandate Attestation**: Bind signed HTTP requests directly to verified human IntentMandate tokens proving authorized purchasing authority
- **Edge CDN Fast-Track Negotiator**: Upgrade standard browser sessions into certified machine buyer sessions, bypassing CAPTCHAs and unlocking dedicated /agentic/ endpoints
