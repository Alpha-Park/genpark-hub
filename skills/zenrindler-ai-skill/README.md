## 🌟 Highlights & Core Features

- **Web-to-MCP Compiler**: Deconstruct target storefront into strongly typed remote Model Context Protocol (MCP) server endpoints
- **Zero-Screenshot Execution**: Eliminate visual computer-use token bloat by routing actions through deterministic headless DOM primitives
- **Self-Healing Selector Relay**: Neutralize marketing popups, cookie consent overlays, and CSS layout shifts via semantic landmark heuristics
- **Atomic Action Pipeline**: Execute complex multi-step shopping funnels (search, filter, variant pick, stage cart) in sub-200ms with 95% token savings

- `zenrindler_audit`: Non-destructive state assessment and discrepancy scanner.
