## 🌟 Highlights & Core Features

- **Game-Theoretic Bargaining Driver**: Execute automated multi-round concession protocols against merchant pricing bots
- **BATNA Reservation Modeler**: Calculate strict walk-away prices based on real-time cross-merchant alternative baselines
- **Multi-Issue Concession Trader**: Offer fulfillment flexibility (slow ground delivery, off-peak shifts) and add-ons to extract cash discounts
- **Anti-Gouging Shield**: Suppress fake scarcity countdowns and neutralize device-type dynamic price discrimination

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenpact workflow
npx genpark run zenpact --demo

npx genpark run zenpact --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenpact_execute`: Primary autonomous execution tool with schema validation.
- `zenpact_audit`: Non-destructive state assessment and discrepancy scanner.
