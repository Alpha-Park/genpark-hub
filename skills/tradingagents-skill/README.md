## 🌟 Highlights & Core Features

- **Trigger Monitor**: Check technical indicators and price levels locally in real-time
- **Trade Simulator**: Run paper trading simulations to backtest strategies safely
- **Order Executer**: Securely interface with API endpoints for mock order loop routing

---

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute tradingagents workflow
npx genpark run tradingagents --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run tradingagents --execute
```

## 🛠 MCP Tools & Agent Protocol
- `tradingagents_execute`: Primary autonomous execution tool with schema validation.
- `tradingagents_audit`: Non-destructive state assessment and discrepancy scanner.
