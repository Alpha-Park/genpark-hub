## 🌟 Highlights & Core Features

- **Procedural Due Process Sentry**: Detects violations of state HOA laws (Florida FS § 720 14-day notice, California Davis-Stirling 10-day rule, Texas Prop Code 30-day cure) to legally void arbitrary fines.
- **Selective Enforcement Comparative Grid**: Organizes geotagged neighbor photo evidence proving disparate treatment, legally waiving the HOA's authority to enforce petty covenants.
- **CC&R Bylaws Decompiler**: Ingests lengthy community governing documents to identify ultra vires board edicts and statutory protections (solar panel installation, drought-tolerant landscaping, EV chargers).
- **Formal Hearing Brief & Fine Rescission Package**: Auto-compiles formal board dispute packets with case citations, freezing penalties and blocking property liens.

---

## 🚀 Quick Start & CLI Usage

```bash
# Ingest HOA violation letter and check state notice compliance
npx genpark run zenhoa --notice "notices/hoa_trash_fine.pdf" --state "FL" --fine 500

# Assemble selective enforcement comparative grid from neighbor photos
npx genpark run zenhoa --case-id "HOA-20261101-A8B9" --add-evidence "photos/neighbor_comparables/"
```

## 🛠 MCP Tools Exposed

- `zenhoa_parse_notice`: Ingests and extracts violation codes, dates, and fine escalations.
- `zenhoa_audit_due_process`: Validates statutory notice and hearing compliance under state HOA laws.
- `zenhoa_evaluate_selective_enforcement`: Analyzes photo exhibits of neighboring properties for waiver defenses.
- `zenhoa_compile_hearing_package`: Generates formal hearing defense briefs and certified legal demand notices.
