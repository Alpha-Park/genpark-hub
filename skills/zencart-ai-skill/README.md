## 🌟 Highlights & Core Features

- **Federated Cart Manager**: Maintain unified real-time cart state across Shopify, Amazon, and DTC stores
- **Price-Drop Radar**: Continuously monitor historical price baselines and alert on genuine flash sales
- **Knapsack Shipping Optimizer**: Solve multi-merchant split orders to hit free-shipping tiers and maximize coupon stacking
- **Post-Purchase Price Arbitrageur**: Auto-monitor 14/30-day merchant price guarantees and claim automated refunds

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zencart workflow
npx genpark run zencart --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zencart --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zencart_execute`: Primary autonomous execution tool with schema validation.
- `zencart_audit`: Non-destructive state assessment and discrepancy scanner.
