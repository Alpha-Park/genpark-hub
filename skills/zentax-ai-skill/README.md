## 🌟 Highlights & Core Features

- **County Tax Parcel Ingestion**: Extract parcel numbers, assessed land/improvement values, millage rates, and protest filing countdown clocks
- **AMA Characteristic Defect Audit**: Detect county property database errors in square footage, room counts, building grade, and effective age
- **ML Comparable Sales Adjustment Grid**: Select arms-length neighborhood sales and apply paired regression adjustment matrices for lot size, age, and condition
- **Uniform & Equal Equity Ratio Arbiter**: Analyze assessment-to-market ratios across peer properties to substantiate constitutional unequal appraisal claims
- **Deferred Maintenance Deduction**: Compile contractor bids and photographic proof of foundation cracks, aging roofs, and structural defects into cost-to-cure deductions

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zentax workflow
npx genpark run zentax --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zentax --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zentax_execute`: Primary autonomous execution tool with schema validation.
- `zentax_audit`: Non-destructive state assessment and discrepancy scanner.
