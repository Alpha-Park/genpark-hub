## 🌟 Highlights & Core Features

- **Human Task Dispatcher**: Decompose physical in-store inspections, pickups, and verifications into geo-fenced micro-gigs
- **Deterministic Escrow Engine**: Lock bounty funds in programmatic smart escrow until multi-modal proof is validated
- **Agent Financial Firewall**: Enforce non-LLM hard spending limits, payee whitelists, and anti-jailbreak transaction ceilings
- **Immutable Proof Ledger**: Anchor user commands, contractor signatures, and GPS-tagged proof photos in tamper-proof store

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenman workflow
npx genpark run zenman --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenman --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenman_execute`: Primary autonomous execution tool with schema validation.
- `zenman_audit`: Non-destructive state assessment and discrepancy scanner.
