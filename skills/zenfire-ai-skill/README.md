## 🌟 Highlights & Core Features

- **KYA Identity Attester**: Issue cryptographic proof-of-delegation tokens bound to human principal
- **Programmatic Budget Wallet**: Sandbox funds with hard transaction ceilings and merchant whitelists
- **Anti-403 Gateway Negotiator**: Transmit X-Agent-KYA-Token headers to satisfy merchant WAF anti-bot checks
- **Crypto Transaction Auditor**: Maintain append-only cryptographic ledger and dispatch real-time mobile push notifications

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenfire workflow
npx genpark run zenfire --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenfire --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenfire_execute`: Primary autonomous execution tool with schema validation.
- `zenfire_audit`: Non-destructive state assessment and discrepancy scanner.
