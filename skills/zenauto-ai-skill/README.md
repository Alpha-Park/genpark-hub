## 🌟 Highlights & Core Features

- **Days-on-Lot Leverage Radar**: Monitor regional dealer inventory aging (>60d) and Market Days Supply (MDS >80d) to maximize buyer negotiation leverage
- **Monroney Window Sticker Deconstruction**: Cross-reference factory window stickers against dealer proposals to identify and strip deceptive add-ons ($1,500 ceramic coatings, $895 nitrogen fills, $995 doc fees)
- **MMR Wholesale Auction Arbiter**: Benchmark trade-ins against real-time Manheim Market Report (MMR) auction transactions to decouple trade-in value from new car pricing
- **Anonymous Multi-Dealer RFQ Engine**: Issue standardized quote requests with ephemeral aliases to 5-15 regional dealers within 150 miles demanding itemized Out-the-Door (OTD) price sheets
- **Game-Theoretic OTD Counter-Bidding**: Run structured bilateral counter-offer rounds across competing dealer quotes to drive price down to wholesale regional floor

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenauto workflow
npx genpark run zenauto --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenauto --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenauto_execute`: Primary autonomous execution tool with schema validation.
- `zenauto_audit`: Non-destructive state assessment and discrepancy scanner.
