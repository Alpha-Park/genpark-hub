## 🌟 Highlights & Core Features

- **Universal Product Resolver**: Parse variant IDs, live stock, and base pricing across any arbitrary e-commerce URL
- **Self-Healing Checkout Driver**: Navigate dynamic checkout DOMs, payment iframes, and address forms autonomously
- **Residential Session Relay**: Route requests via resident browser profiles to neutralize bot heuristics
- **Cost and Coupon Arbitrageur**: Auto-test verified merchant discount codes and calculate exact zip-code tax/shipping

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenrye workflow
npx genpark run zenrye --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenrye --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenrye_execute`: Primary autonomous execution tool with schema validation.
- `zenrye_audit`: Non-destructive state assessment and discrepancy scanner.
