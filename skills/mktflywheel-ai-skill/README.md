## 🌟 Highlights & Core Features

- **Marketing Strategist**: Structural cross-channel campaign maps
- **Bulk Copy**: Generate highly tailored landing page ad copies
- **SEO Engine**: Run immediate organic search keyword audit

---

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute mktflywheel workflow
npx genpark run mktflywheel --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run mktflywheel --execute
```

## 🛠 MCP Tools & Agent Protocol
- `mktflywheel_execute`: Primary autonomous execution tool with schema validation.
- `mktflywheel_audit`: Non-destructive state assessment and discrepancy scanner.
