## 🌟 Highlights & Core Features

- **PSTN Telephony Orchestrator**: Dispatch outbound telephone calls to brick-and-mortar storefronts, pharmacies, and service desks
- **Sub-Second Voice Engine**: Maintain conversational turn-taking latency below 600ms with dynamic noise suppression and interruption handling
- **Offline Inventory Extractor**: Interrogate retail clerks to verify physical on-shelf stock and lock behind-the-counter hold confirmations
- **Live Whisper & Takeover Gate**: Stream real-time call transcription to paired WhatsApp/Telegram with 1-tap live human phone takeover

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenvoice workflow
npx genpark run zenvoice --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenvoice --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenvoice_execute`: Primary autonomous execution tool with schema validation.
- `zenvoice_audit`: Non-destructive state assessment and discrepancy scanner.
