## 🌟 Highlights & Core Features

- **True Value Matrix**: Evaluate purchases across price integrity, material durability, ESG verification, and net cost-per-wear (CPW)
- **Secondary Resale Forecaster**: Model 3-year depreciation curves based on millions of Vestiaire, RealReal, and Poshmark transactions
- **Greenwashing Shield**: Audit marketing claims against third-party certifications (OEKO-TEX, GOTS, B-Corp) with zero tolerance for fake eco-tags
- **Ethical Dupe Engine**: Discover affordable, responsibly crafted alternatives to luxury items without resorting to sweatshop knockoffs

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenphia workflow
npx genpark run zenphia --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenphia --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenphia_execute`: Primary autonomous execution tool with schema validation.
- `zenphia_audit`: Non-destructive state assessment and discrepancy scanner.
