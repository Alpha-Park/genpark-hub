## 🌟 Highlights & Core Features

- **CPT/HCPCS Code Deconstruction**: Ingest multi-page itemized hospital bills and EOBs to map every line item to 5-digit procedure and revenue codes
- **Upcoding & Unbundling Sentry**: Apply CMS NCCI bundling edits to strip fragmented supply charges and audit emergency room severity levels
- **CMS Price Transparency MRF Benchmark**: Cross-reference hospital federal machine-readable files to benchmark chargemaster prices against discounted cash and median negotiated rates
- **No Surprises Act Statutory Radar**: Detect illegal out-of-network balance billing for emergency or ancillary hospital services and trigger federal PPDR disputes
- **IRS 501(r) Charity Care Write-Off**: Match household income to hospital Financial Assistance Policies (FAP) to mandate 50-100% debt forgiveness

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenbill workflow
npx genpark run zenbill --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenbill --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenbill_execute`: Primary autonomous execution tool with schema validation.
- `zenbill_audit`: Non-destructive state assessment and discrepancy scanner.
