## 🌟 Highlights & Core Features

- **Context Card Compiler**: Structure raw catalog feeds into high-density 'Who it's for, When to recommend, Why it fits' vectors
- **Multi-Rail Distributor**: Broadcast product endpoints across ACP, UCP, MCP, and Agent Skills rails
- **Sovereign Checkout Router**: Enforce headless checkout handoff directly to merchant's domain
- **Agent Attribution Engine**: Track LLM referral traffic, prompt intent categorizations, and GEO rankings

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zennile workflow
npx genpark run zennile --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zennile --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zennile_execute`: Primary autonomous execution tool with schema validation.
- `zennile_audit`: Non-destructive state assessment and discrepancy scanner.
