## 🌟 Highlights & Core Features

- **Peer Handshake**: End-to-end encrypted ED25519 agent discovery tunnel
- **Collective Buyer**: Cross-user cart bundling and BOGO discount arbitrage
- **ZK Schedule Aligner**: Zero-knowledge meeting/dining overlap calculation
- **P2P Split Settler**: Proportional bill division with dual-HITL approval gate

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zenpeer workflow
npx genpark run zenpeer --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zenpeer --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zenpeer_execute`: Primary autonomous execution tool with schema validation.
- `zenpeer_audit`: Non-destructive state assessment and discrepancy scanner.
