## 🌟 Highlights & Core Features

- **Spatial-Temporal Constraint Engine**: Synthesize end-to-end multi-modal itineraries resolving minimum connection times (MCT), jetlag, and operating hours
- **GDS & NDC Wholesale Arbitrageur**: Query direct airline NDC and GDS channels for wholesale tariffs with 24-hr fare freeze and post-booking price drop tracking
- **In-Trip Disruption Recovery Sentinel**: Continuously monitor ADS-B air telemetry to automatically trigger interline rebooking and hotel voucher locks
- **Multi-Party Consensus & Split AP2 Mandates**: Harmonize group travel preferences via A2A mesh and dispatch cryptographically signed proportional payment mandates

## 🚀 Quick Start & CLI Usage

```bash
# Ingest or execute zentrip workflow
npx genpark run zentrip --demo

# Run with custom parameters in local OpenClaw runtime
npx genpark run zentrip --execute
```

## 🛠 MCP Tools & Agent Protocol
- `zentrip_execute`: Primary autonomous execution tool with schema validation.
- `zentrip_audit`: Non-destructive state assessment and discrepancy scanner.
